## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

## Flexbox

В проекте используются:

- `display: flex` для навигации, кнопок и карточек;
- `flex-direction: column` для вертикального расположения элементов внутри карточки;
- `justify-content: space-between` для распределения элементов шапки и подвала;
- `align-items: center` для вертикального выравнивания в шапке;
- `flex-wrap: wrap` для переноса элементов навигации и кнопок;
- `gap` для задания расстояния между элементами;
- `margin-top: auto` для прижатия кнопки к низу карточки товара.

## CSS Grid

В проекте используются:

- `display: grid` для сетки каталога товаров;
- `grid-template-columns: repeat(auto-fit, minmax(280px, 1fr))` для адаптивной раскладки;
- автоматический расчёт количества колонок без медиа-запросов;
- `gap` для одинаковых отступов между карточками;
- двумерное управление строками и колонками одновременно.

## Фиксированное меню

В проекте используются:

- `position: sticky` для фиксации шапки при прокрутке;
- `top: 0` для точки прилипания к верхнему краю;
- `z-index: 100` для отображения шапки поверх контента;
- непрозрачный `background-color` для предотвращения просвечивания контента;
- `border-bottom` для визуального отделения шапки от содержимого;
- сохранение естественного положения шапки при загрузке страницы.

## Методология БЭМ

В проекте используются:

- блоки: `.header`, `.nav`, `.product-card`, `.form-field`, `.footer`;
- элементы: `.nav__list`, `.nav__item`, `.nav__link`, `.product-card__title`, `.form-field__input`;
- модификаторы: `.form-field--checkbox`, `.section--products`, `.button--secondary`;
- разделение ответственности между блоком и его элементами;
- независимость блоков для переиспользования в разных частях страницы;
- низкая специфичность селекторов для предсказуемости стилей.
