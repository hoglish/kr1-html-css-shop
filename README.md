# Учебный frontend-проект: Интернет-магазин

## Описание проекта

Данный проект представляет собой многостраничный сайт учебного интернет-магазина, разработанный в рамках дисциплины «Фронтенд и бэкенд разработка». Сайт включает в себя главную страницу с популярными товарами, каталог с фильтрацией, страницу услуг, контакты и отзывы.

Проект демонстрирует применение современных подходов к вёрстке: использование CSS-переменных, методологии БЭМ, Flexbox и CSS Grid для построения адаптивных раскладок, а также базовую JavaScript-логику для работы с модальными окнами и формами.

## Реализованный функционал

### Навигация и хедер
- Липкий хедер (`position: sticky`) который остаётся видимым при скролле
- Горизонтальное меню на Flexbox
- Анимированное подчёркивание ссылок через псевдоэлемент `::after`
- Подсветка активного раздела (текущей страницы)
- Кнопка переключения тёмной темы (🌙/☀️)

### Карточки товаров
- Изображение товара
- Название и краткое описание
- Цена
- Две кнопки: "Заказать" и "Подробнее"
- Hover-эффект с подсветкой границы
- Кнопка "Заказать" прижата к низу карточки через `margin-top: auto`

### Модальные окна
- **Окно заказа**: открывается при клике на "Заказать", содержит форму с валидацией
- **Окно деталей товара**: открывается при клике на "Подробнее", показывает большое изображение и полное описание
- Закрытие по кнопке "×" или клику вне окна
- Передача названия товара между окнами

### Форма заявки
- Поля: имя, e-mail, телефон, дата связи, тема, комментарий
- HTML-валидация через атрибуты `required`, `minlength`, `pattern`, `type="email"`
- Визуальная подсветка ошибочных полей через `aria-invalid`
- Сообщение об успешной отправке
- Чекбокс согласия на обработку данных

### Фильтры каталога
- Фильтр по категориям (чекбоксы: Все товары, Популярные, Новинки)
- Фильтр по цене (диапазон "От" и "До")
- JavaScript логика скрытия/показа карточек
- Поддержка опции "Все товары"

### Тёмная тема
- Переключение между светлой и тёмной темой
- Сохранение выбора в `localStorage` (работает между страницами)
- Автоматическое определение системной темы через `prefers-color-scheme`
- Плавные переходы цветов через `transition`
- CSS-переменные для мгновенной смены цветов

## Технологии

### HTML5
- Семантическая разметка (`header`, `main`, `section`, `article`, `aside`, `footer`)
- Модальные окна через тег `<dialog>`
- Формы с различными типами полей
- Data-атрибуты для хранения информации о товарах
- ARIA-атрибуты для доступности
- Open Graph разметка для соцсетей

### CSS3
- CSS-переменные (`:root`) для цветов, отступов, радиусов
- Flexbox для навигации и внутренней структуры карточек
- CSS Grid для сеток товаров и макета каталога
- Именованные области Grid (`grid-template-areas`)
- Псевдоэлементы (`::after`) для декоративных линий
- Псевдоклассы (`:hover`, `:focus-visible`, `:disabled`)
- Sticky positioning для хедера
- Media queries для базовой адаптивности

### JavaScript
- Работа с DOM через `querySelector` и `getElementById`
- Обработка событий (`click`, `submit`)
- Модальные окна через `showModal()` и `close()`
- Валидация форм через `checkValidity()`
- Data-атрибуты через `dataset`
- LocalStorage для сохранения настроек
- Делегирование событий
- Безопасные проверки на существование элементов

### Методология БЭМ
Все классы организованы по методологии Блок-Элемент-Модификатор:

**Блоки:**
- `.header`, `.footer`, `.hero`, `.section`
- `.product-card`, `.service-card`, `.review_examp`
- `.nav`, `.button`, `.form-field`
- `.catalog-layout`, `.catalog-filters`

**Элементы:**
- `.header__container`, `.nav__list`, `.nav__item`, `.nav__link`
- `.product-card__title`, `.product-card__price`, `.product-card__button`
- `.form-field__label`, `.form-field__input`

**Модификаторы:**
- `.nav__link--active` (активная страница)
- `.button--secondary` (вторичная кнопка)
- `.form-field--checkbox` (модификатор для чекбокса)

## Использование Flexbox

В проекте Flexbox используется для:

1. **Навигационное меню** - горизонтальное расположение пунктов меню с равными отступами
2. **Хедер** - выравнивание логотипа и навигации (`justify-content: space-between`)
3. **Внутренняя структура карточек** - вертикальное расположение элементов через `flex-direction: column`
4. **Кнопки внутри карточек** - прижатие кнопки к низу через `margin-top: auto`
5. **Футер** - распределение элементов (`justify-content: space-between`)
6. **Форма фильтров** - расположение полей ввода

Основные свойства:
```css
display: flex;
flex-direction: column;
justify-content: space-between;
align-items: center;
gap: var(--space-md);
flex-wrap: wrap;
```

## Использование CSS Grid

В проекте CSS Grid используется для:

1. **Сетка карточек товаров** - адаптивная сетка с автоматическим расчётом колонок
2. **Макет страницы каталога** - две колонки (фильтры + товары)
3. **Сетка отзывов** - карточки в несколько колонок
4. **Форма заявки** - расположение полей формы

Основные свойства:
```css
display: grid;
grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
grid-template-columns: 260px 1fr;
grid-template-areas: "filters products";
gap: var(--space-lg);
```

## Тёмная тема

Реализована система переключения тем с использованием CSS-переменных:

**Светлая тема (по умолчанию):**
- Белый фон
- Тёмный текст
- Синий акцентный цвет

**Тёмная тема:**
- Тёмно-серый фон
- Светлый текст
- Голубой акцентный цвет

Переменные переопределяются через атрибут `data-theme="dark"` на теге `<html>`:

```css
[data-theme="dark"] {
  --color-bg: #121212;
  --color-text: #e0e0e0;
  --color-primary: #4da3ff;
  /* ... другие переменные */
}
```

JavaScript управляет переключением и сохраняет выбор в `localStorage`, поэтому тема сохраняется при переходе между страницами.

## Проверка функционала

### Навигация
1. Открыть любую страницу
2. Убедиться что меню работает и подсвечивает текущую страницу
3. Проверить переходы между страницами
4. Проверить подчёркивание при наведении

### Модальные окна
1. Нажать "Заказать" на любой карточке
2. Заполнить форму и отправить
3. Нажать "Подробнее" и проверить информацию о товаре
4. Нажать "Заказать этот товар" внутри окна деталей

### Фильтры
1. Перейти в каталог
2. Выбрать категорию "Новинки"
3. Ввести диапазон цен (например, от 1200 до 2000)
4. Нажать "Применить"
5. Убедиться что остались только подходящие товары

### Тёмная тема
1. Нажать на кнопку 🌙 в хедере
2. Убедиться что тема переключилась
3. Перейти на другую страницу
4. Проверить что тема сохранилась
5. Обновить страницу и проверить что тема осталась

## Известные ограничения

- Фильтры работают только на клиентской стороне (нет backend)
- Форма не отправляет данные на сервер (только валидация)
- Изображения товаров учебные (placeholder)
- Адаптивность базовая (основные брейкпоинты для мобильных)
- Отзывы и услуги статические (нет динамического добавления)
